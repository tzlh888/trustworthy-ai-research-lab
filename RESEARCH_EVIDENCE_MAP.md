# Trustworthy AI — Research Evidence Map

This index maps public claims to the smallest useful evidence trail. `VERIFIED` means the cited repository artifacts or tests directly support the bounded claim; `REPORTED` means the repository records the claim but it is owner-declared or was not independently reproduced here; `NOT VERIFIED` means the required evidence does not exist in the public record.

V2 contains the primary model-comparison results. V3.1 is a separate post-hoc annotation-sensitivity analysis over frozen V2 predictions and scores; it is not a new model evaluation or independent test.
