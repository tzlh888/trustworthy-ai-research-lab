# 150-Word Project Description

I investigated whether evidence-retrieval signals can improve error-risk ranking for scientific claim verification. Using official SciFact data, I built a reproducible BM25, sentence-selection, and NLI pipeline, then compared a frozen NLI-only logistic risk model with Evidence-Aware Risk Scoring (EARS), which adds retrieval-margin and evidence-conflict features. I separated fit, calibration, and Internal Test claims using connected cited-document groups and froze models and predictions before opening test labels. On 88 eligible Internal Test claims, the base verifier achieved 0.488636 accuracy. EARS improved AURC from 0.300833 to 0.264987; the paired difference was -0.035846 with a 95% grouped-bootstrap interval of [-0.076087, -0.003447]. However, at 80% coverage EARS was worse than the NLI-only model: 0.457143 versus 0.428571 selective risk. Therefore H1 was inconclusive under the preregistered joint criterion. The project emphasizes leakage prevention, reproducibility, transparent negative results, and careful separation of confidence, abstention, and evidence insufficiency. H2 and H3 were not evaluated in this study.
