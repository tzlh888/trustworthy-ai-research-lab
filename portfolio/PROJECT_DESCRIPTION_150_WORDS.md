# 150-Word Project Description

This project investigated whether evidence-retrieval signals can improve error-risk ranking for scientific claim verification. Using SciFact data, it implemented a BM25, sentence-selection, and NLI pipeline, then compared a frozen NLI-only logistic risk model with Evidence-Aware Risk Scoring (EARS), which adds retrieval-margin and evidence-conflict features. Fit, calibration, and Internal Test claims were separated by connected cited-document groups, and models and predictions were frozen before test-label access. On 88 eligible Internal Test claims, EARS improved AURC from 0.300833 to 0.264987 but worsened 80%-coverage selective risk from 0.428571 to 0.457143. H1 was therefore inconclusive under the internally frozen joint criterion. V2 same-dataset Dev results did not establish a stable EARS advantage, and no compatible cross-dataset replication was completed. The project emphasizes leakage controls, negative-result retention, and evidence boundaries. The human owner supplied objectives and retains publication responsibility; AI-assisted systems supported implementation, execution, auditing, and drafting. No external preregistration or unaided implementation is claimed.
