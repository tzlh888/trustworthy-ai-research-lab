# Evidence-Aware Risk Scoring for Scientific Claim Verification

Scientific claim-verification systems can produce confident but incorrect answers, so this project asks a practical second question: can a system estimate which of its own predictions are most likely to be wrong? The study examines Evidence-Aware Risk Scoring (EARS), a selective-prediction method that combines uncertainty from a natural-language-inference model with two label-free evidence signals: the margin between the top two BM25 retrieval scores and disagreement among retrieved evidence sentences.

The base verifier retrieves scientific abstracts, selects sentences by lexical overlap, applies a pinned NLI model, and aggregates sentence predictions into SUPPORT, CONTRADICT, or NO_RELATION. A matched NLI-only risk model (B1) is compared with B1 plus each evidence feature and with Full EARS. All risk models use the same claims, error labels, preprocessing, and L2 logistic regression. The original frozen Internal Test contained 88 eligible claims. EARS improved average risk–coverage ranking there, but worsened risk at the prespecified 80% coverage point, so the original conclusion remains **H1 INCONCLUSIVE**.

This upgrade added label-gated evaluation on the official SciFact Dev split: 188 eligible claims in 164 connected groups. Full EARS did not reliably outperform B1. Its AURC was 0.2884 versus 0.2816 for B1, while R80 was 0.4000 versus 0.4133. Paired group-bootstrap intervals crossed zero for both differences. The retrieval-margin feature did not help; the evidence-conflict feature showed some conditional signal but no stable endpoint improvement. A stronger DeBERTa-based NLI candidate also failed to improve the verifier: accuracy fell from 0.4894 to 0.4734.

The failure analysis is the project's strongest new result. SUPPORT recall was only 0.323, despite 0.842 gold-document recall at five retrieved documents. Gold-sentence recall fell to 0.516, showing that finding a relevant paper is not the same as retaining the decisive evidence. Historical AURC and R80 disagreed because five claims entered and five left the accepted set at the 80% boundary; five entering claims were errors, compared with three leaving errors.

The project therefore makes a bounded contribution: it provides a reproducible framework for testing whether retrieval and evidence-consistency signals add value beyond NLI uncertainty, and it identifies when that idea fails. It does not claim external replication, calibrated probabilities, deployment readiness, peer review, or institutional endorsement. The human project owner remains responsible for the research claims; AI tools assisted implementation, statistical checks, experiment organization, and documentation.
